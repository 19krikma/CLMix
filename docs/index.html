CLMix

Aux-send mixing for the DiGiCo Q225 Quantum.

Windows desktop app · Android and iOS clients · your network only

Download for Windows View source on GitHub

What it is

CLMix hands each performer their own monitor mix on their own phone. A desktop app on the same network as the console does the talking — it speaks OSC to a DiGiCo Q225 Quantum, mirrors the channel names, aux buses, banks and snapshots the console reports, and re-serves the parts each person is allowed to touch to the Android and iOS apps over Wi-Fi.

Everything happens on your own network. There is no CLMix account, no cloud service, and no server run by anyone but you — the phones talk to your desktop machine and nowhere else.

How it works

  • Console

    Q225 Quantum

    Reached over OSC on the desk's own send and receive ports.

  • Desktop

    CLMix on Windows

    Mixes from the desk itself and runs the server the phones connect to.

  • Stage

    Phones

    Each performer gets one aux bus and nothing else, over local Wi-Fi.

The phones find the desktop by themselves: the server advertises itself over mDNS/Bonjour, so nobody has to read an IP address off the back of a laptop mid-soundcheck. Typing one in by hand still works when the network blocks multicast.

What it does

  • Per-performer mixes

    Level, pan and per-send mute for every input channel, on the aux bus that person is assigned to.

  • Scoped accounts

    Each login is tied to one aux bus and one snapshot (or to all of either). Passwords are stored salted and hashed, on your machine.

  • Snapshot aware

    Recall a different snapshot on the desk and accounts scoped to another one stop being able to move anything.

  • Their mix, not the mix

    The phone's mute is the console's per-send on/off, so muting a channel drops it out of that one wedge — never out of the room.

  • Presets

    Save an aux mix under a name from the phone and pull it back later. Presets recall as ordinary fader moves the desk sees like any other.

  • Stays logged in

    A session token survives the app being closed and relaunched, and ages out on its own once it stops being used.

  • Hidden buses

    Aux buses that aren't monitor mixes can be kept out of the list the phones ever see.

  • Logs and backups

    Searchable local activity logs for troubleshooting, and a backup and restore for settings, accounts and presets.

  • Light and dark

    Both themes on all three clients, for the pit and for the daylight load-in alike.

Getting it

Windows
Download the installer from the latest release. It installs like any other Windows app and updates itself from Help › About.
Android
Ships alongside the desktop release. Point it at the desktop machine — it will usually find it on its own.
iOS
Built from source: see ios/README.md in the repository.
macOS / Linux
No packaged build, but the desktop app runs from source on both — pip install -r requirements.txt, then python main.py.
You'll need
A DiGiCo Q225 Quantum reachable over the network, and the phones on the same network as the desktop machine.

Privacy

CLMix collects nothing. There is no analytics, no advertising and no crash reporting, and no server the developer operates for it to talk to. Logins, mixer commands and presets never leave the network they were sent on. The one request that goes out is the desktop app's anonymous check of GitHub's public API for a newer release.
